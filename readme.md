# Jardim Zen

O objetivo deste projeto era de criar uma composição interativa e generativa no Vs Code. Como objetivo principal para esta minha proposta é de criar um espaço visual e sonoro relaxante onde o programa reage em tempo real às ações do utilizador a partir do toque e teclado, utilizando ainda a ferramenta If/Else.
Para este presente trabalho foi necessário a utilização de IA para me explicar certas coisas para que este projeto pudesse dar certo. 
Utilizei os código if / else e else if em certos sitios para garantir a interatividade em tempo real. 
Para este projeto o if começa tudo, faz com que o programa pergunte se o rato está no canto superior esquerdo, se a resposta for verdadeira, aplica logo a cor correspondente, neste caso a azul.
Caso contrário, o processo vai avançando para o primeiro else if, para assim testar se o cursor está no canto superior direito. Se falhar novamente passa para o segundo else if para verificar o canto inferior esquerdo. Por fim, se nenhuma destas três zonas anteriores for verdadeira, o else assume automaticamente que o rato está no canto inferior direito e aplica a sua cor.
Já para as formas geométricas o processo é o mesmo. Quando o computador vai desenhar cada onda individual, ele inicia a verificação com um if para saber se o número é 1, desenhando um círculo. Caso não seja, o programa avança para os else if seguintes, testando se o número é 2 para desenhar um quadrado, 3 para um triângulo, ou 4 para uma estrela.
A implementação da música e dos sons ambiente neste projeto foi algo fundamental e foi feita utilizando a Web Audio API, nativo do navegador, o que significa que o programa gera os sons matematicamente em tempo real, sem precisar de carregar ficheiros de áudio externos ou preocupar-se com direitos de autor. O processo começa com um código que indica que a música está inicialmente desligada (let musicaIniciada = false), fazendo assim com que o navegador bloqueie o som até alguem tocar no ecrã. Sempre que é dado um clique no ecrã, o código corre automaticamente a função mousePressed(). Utilizei ainda o if na musica iniciada para assim começar a dar a musica após a primeira interaçõ com a tela.
